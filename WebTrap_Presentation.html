The Problem

  • Modern cyber attacks are highly automated.
  • Hackers use botnets to scan thousands of servers a second.
  • Traditional firewalls block traffic but provide zero intelligence on the attacker.
  • Security Analysts suffer from severe "Alert Fatigue".

The Solution: WebTrap

Instead of passively blocking, we use Deception Technology.

  • Lure: A fake, vulnerable Enterprise Gateway.
  • Trap: Silently logs credentials and payloads.
  • Profile: Automatically traces the hacker's IP, ISP, and Location.
  • Defend: Wastes attacker resources via Tarpitting.

System Architecture

Built exclusively using Python and Bash for zero-dependency deployment.

Advanced Capabilities

  • Deep Packet Inspection (DPI): Regex engine detects SQLi, XSS, and Path Traversal.
  • Tarpitting: Intentionally delays responses by 5 seconds to freeze automated scanning tools.
  • Auto-Deduplication: Caches attacker IPs to prevent API rate-limiting and alert spam.
